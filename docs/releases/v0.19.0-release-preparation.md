## Copy-ready GitHub Release description

# Project Ragnarok v0.19.0 — Island Survival Playtest

This Windows x64 alpha playtest brings significant improvements to survival, combat, resource gathering, NPC behaviour, inventory management, and character progression. **The game is still under active development; some systems are provisional and co-op has not been fully verified on two physical PCs.**

### Added
- Custom user-created resource icons now appear as camera-facing ground pickups.
- Trophies of Valour progression for six wildlife species and three infected categories, with six rarity milestones and prototype character attachments for both genders.
- NPC combat stances, health inspection, food/water/treatment use, and return-home orders after a survivor dies.
- Ctrl-click quick transfers, nearby matching-chest stacking, crafting category tabs, and inline recipe ingredient icons.
- Mortar & Pestle crafting (1 Stone Slab + 1 Cobble; Hammer + Chisel).
- Workbenches provide on-person recipes as well as bench-specific recipes.
- Directional player markers, rotatable character preview, and a branded Windows application icon.

### Changed and fixed
- Hardened death/successor checkpoint writes and validation. Two scripted Windows succession flows passed (with TP spent and unspent); the original failed save was not available for root-cause reproduction.
- Corrected mining eligibility and target detection. A naturally generated boulder yielded a Stone Slab after five strikes in testing.
- Revised gravity-aware ranged aiming to better target elevated enemies.
- Improved chest and inventory slot sizing, hotbar layout, and auto-gather handling of dedicated tools and recoverable arrows.
- Adjusted healthy swimming depth and suppressed footstep audio while swimming; infected continue to sink instead of swimming.

### Testing
- Native Windows fixture: 91 checks at 1280 × 720 and 83 at 1024 × 576.
- Automated suites include 65 Champion, 95 Survival, and 254 Water/Inventory checks.
- Isolated updater test installed and automatically relaunched v0.19.0 without changing fixture save/settings data.
- Some older suites reproduce baseline failures, so not all regression categories are clean.
- Real GitHub-delivered updating, two-PC LAN play, complex NPC encounters, and the full visual quality of Trophies of Valour remain to be verified.

### Known limitations
- Trophy models and rarity effects remain prototypes and need refinement.
- Ordinary corpse burning lacks an available torch acquisition path.
- Predictive leading of moving ranged targets is not implemented.
- Advanced NPC combat/leashing/pathfinding and cross-client behaviours need extended playtests.
- The original failure-causing successor checkpoint could not be recovered, so the exact historic failure remains unconfirmed.
- This is an alpha/playtest release; issues are expected.

### Installation
1. Download `ProjectRagnarok-v0.19.0-Windows-x64.zip`.
2. Extract the complete ZIP to a writable folder outside Program Files.
3. Keep `ProjectRagnarok.exe`, `RagnarokUpdater.exe`, and `release-version.txt` together.
4. Launch `ProjectRagnarok.exe`.
5. Create a new world for testing. The game stores profile data under the standard Godot app data directory.

**Windows x64 only.** Keep backups of your existing worlds. For multiplayer, all participants should use the same game build.
