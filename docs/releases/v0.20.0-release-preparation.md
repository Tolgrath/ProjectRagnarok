## Copy-ready release notes

# Project Ragnarok v0.20.0 — Survival & Customization Update

⚔️ **A new chapter of Project Ragnarok's Windows alpha playtest is here!**

This update expands Viking character creation, makes medical treatment more flexible, improves gathering feedback and building interactions, and refines supernatural presentation. Project Ragnarok remains an **alpha playtest**; visuals, AI, and several systems require continued testing.

### What's new
- **Viking identity:** Randomized editable village and survivor names, additional hairstyles, 16 hair colours and a separate bust customization control for female survivors.
- **Resource pickups:** User-created icon billboards are approximately 50% larger, exhausted resource visuals are hidden, and a fixed right-side pickup feed shows amounts gained and inventory totals.
- **Medical care:** Right-click individual wounds to view standard, alternative, temporary and unavailable treatments. A Stitch Kit can permanently close an ordinary scratch without a Basic Wrap. The approved infection-specific requirements remain in force.
- **Construction:** Structure recipes and dedicated Wood Hammer recognition restored, with eligible nearby chest resources available for construction.
- **Corpse management:** Ordinary infected remains now support inspection, Tog binding/dragging, and decapitation using the dedicated axe.
- **Controls and UI:** Improved Escape navigation, an exit confirmation from the main menu, configurable hold/toggle auto-gather, and persistent global UI scale (85–115%).
- **Procession of the Fallen:** Revised raven and spectral figure presentation, plus automatic background-music reduction to make the procession theme easier to hear.

### Testing and reliability
- The final exported Windows executable passed 31 scripted gameplay checks at 1280×720; a preceding export passed 22 at each of 1024×576 and 1920×1080.
- Verification suites: Survival Systems 98, Water and Inventory 276, Champion 65, Guided Appearance 23, and approved icons 11.
- A nine-check settings fixture verified appearance mesh generation, 110% UI scale persistence, hold/toggle auto-gather, invalid-state cancellation, and ordinary-launch restrictions on developer tools.
- Isolated localhost updater installation preserved test world/settings data and obtained a version-specific main-menu receipt.
- Startup-area frame times on a GTX 1660 Ti were similar to v0.19 in the reported benchmark; this is not a stress or co-op benchmark.

### Known limitations
- Restored construction recipe resources provisionally map retired Wood→Log, Plank→Branch, Stone→Cobble; these replacements **require user approval** before treating them as finalized design.
- Building stock works with visible storage within 6 metres, but a guest preview can still display personal-only stock.
- Full drag-and-drop HUD rearrangement is **not implemented**. UI scaling and separate HUD anchors are in place.
- Ordinary corpse burning requires a torch; no standard approved torch acquisition path currently exists.
- Full procession presentation and soundtrack balance still need hands-on verification.
- Developer death/plague testing exists in isolated builds, but direct reanimation, dedicated boss-variant spawning and mineable-node debug fixtures remain incomplete.
- Some legacy Building, Island Integration, Network Stock, Wildlife and Approved Scope tests still fail; older Infection tests log invalid inventory operations. Not every older suite was rerun.
- Real two-PC co-op and the live GitHub update flow for this build are not yet independently verified.

### Installation
1. Download `ProjectRagnarok-v0.20.0-Windows-x64.zip`.
2. Extract the full archive to a writable folder outside Program Files.
3. Keep `ProjectRagnarok.exe`, `RagnarokUpdater.exe` and `release-version.txt` together.
4. Launch `ProjectRagnarok.exe` and continue solo testing. Keep backups of your worlds.
