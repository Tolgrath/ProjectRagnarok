## Automatic updates and Windows security/reputation — research only

- Consider a lightweight launcher or built-in update checker against a controlled GitHub release manifest and SHA-256 verified assets. Do **not** silently overwrite a running game or make releases download arbitrary unsigned files; signed updates and user approval are preferred. Keep an offline playable mode.
- Windows SmartScreen reputation and antivirus warnings: signed binaries with a reputable code-signing certificate and clean installer/export practices help, but no guaranteed instant 'trusted' switch exists; avoid bypass instructions. Check current Microsoft requirements and publisher identity before spending on signing.
